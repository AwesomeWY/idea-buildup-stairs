# 아이디어 빌드업 계단

초등 5학년 바이브코딩 수업에서 "뭘 만들지 모르겠다"는 학생을 위한 웹앱입니다.
먼저 앱 종류를 고르고 질문 5계단에 답하면
AI에게 붙여 넣을 웹앱 주문서(프롬프트)가 자동으로 완성됩니다.

## 앱 종류 4가지
종류마다 계단 질문, 고르기 예시, 갈림길, 주문서 문장이 모두 다릅니다.

| 종류 | 계단 흐름 |
|---|---|
| 📚 학습 도우미 | 과목 → 막히는 곳 / 놀이처럼 → 누가 → 딱 하나 → 그려봐 |
| 🧩 두뇌 게임 | 놀이 → 새 규칙 / 점점 어렵게 → 누가 → 딱 하나 → 그려봐 |
| 💌 친구를 위한 웹앱 | 친구 인터뷰 → 친구의 불편 / 바람 → 누가 → 딱 하나 → 그려봐 |
| 🛠️ 문제해결 | 문제 찾기 → 원인(깜빡함 / 하기 싫음) → 누가 겪나 → 해결 기능 → 그려봐 |

3계단에는 생각을 넓히는 선택 질문(무엇을 잘하게 될까, 어떤 힘이 자랄까 등)이 있습니다.

## 특징
- 로그인 없음, AI 호출 없음(토큰 사용 0). 브라우저만 있으면 작동합니다.
- 학생 답은 그 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다.
- 파일 하나(`index.html`)로 이루어진 정적 사이트입니다.
